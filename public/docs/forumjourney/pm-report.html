9. Lessons Learned

2026-09-08

Test helper opts parameter needs a default when all properties are optional. When a test helper function has all optional properties (partner?: ..., params?: ...), the opts parameter itself must also default to {}. Without a default, calling makeReqRes() with no arguments throws at runtime because property access on undefined fails. Always add = {} when all properties of an opts-style parameter are marked optional.

2026-09-05

A data collection pipeline with no downstream reader is incomplete. The parking adapter wrote facts into normalizedFacts for the entire data collection phase with no consumer — it was only wired into plan content (discoveries[]) later. When adding a new data category, always trace the full path from collection → normalization → consumer in the same sprint. An unread collection is dead weight and its value can't be validated until something reads it.

2026-09-05

Test stubs missing required fields silently test the wrong failure branch. In join.test.ts, the "invalid join code" test was missing password in the request body. The route's required-fields guard (!email || !firstName || !password || !joinCode) caught it first and returned BAD_REQUEST — so the test passed but was testing the missing-fields branch, not the invalid-code branch. When writing a test for a specific error path, ensure all required fields are present so the guard conditions don't intercept the test before it reaches the target code path.

2026-09-02

New routes with where()+orderBy() must ship their Firestore composite indexes in the same commit. venue.ts and speaker.ts added compound queries but no entries to firestore.indexes.json. Without composite indexes, Firestore rejects these queries at runtime. Single-field where() without orderBy() does not require a composite index — only where+orderBy combinations do.

2026-08-31

Use vi.hoisted() when Vitest mock factories must close over reassignable variables. Without hoisting, the variable declaration is hoisted by JS but not initialized before the factory runs — the mock closes over undefined. Pattern: const { mockGet } = vi.hoisted(() => ({ mockGet: vi.fn() })). Required any time a mock factory needs a module-level variable that changes between tests.

2026-08-31

Test files in frontend/src/ must be excluded from the app tsconfig. Vite resolves tsconfig.app.json at build time; if *.test.tsx files are included, Vite attempts to bundle them and fails. Fix: add "exclude": ["src/**/*.test.tsx", "src/**/*.test.ts"] to frontend/tsconfig.app.json.

2026-08-30

Scripts in scripts/ outside npm workspaces must self-configure NODE_PATH. Fix: set process.env.NODE_PATH and call Module._initPaths() before any requires. Any standalone script depending on functions/node_modules packages must do the same.

2026-08-28

New Firestore collections must get a rules stub immediately. Add a named match /X/{docId} stub in the same commit as any new db.collection('X') call. The catch-all allow read, write: if false protects it but intent is invisible without the stub.

2026-08-28

Stage-aware cache TTLs are the right model for time-sensitive sourcing data. Weather sourcing uses 30-min TTL for attend and 4-hour TTL for prepare. Apply the same stage-aware TTL pattern to any future real-time sourcing adapter.
