9. Lessons Learned

2026-09-14 — new this run

Seed scripts must write the exact Firestore field shape the API mapper reads. seed-pittsburgh-city-guide.js wrote weatherByMonth.october as a nested object, but cityGuideFromFirestore() passed values directly to the client and WeatherSection rendered them with {desc} — causing React error #31 (objects not valid as children). The fix was flattening to a plain string. Whenever writing a seed script, read the corresponding mapper and renderer to confirm field shapes match end-to-end. A mismatch is invisible at write time and only surfaces when the field is rendered.

2026-09-14 — new this run

Admission facts (idRequired, idRequirements, checkInProcess) must be populated from venue's official policy before plan goes live. The DisruptHR event was seeded with idRequired: false and no admission policy, but the event is at Rivers Casino which requires government-issued photo ID (21+ only). A guest arriving without ID would be turned away. Any event at a casino, age-gated venue, or venue with non-standard entry requirements must have admission fields populated from the venue's published policy during data entry — do not leave these at default false.

2026-09-09

JSX ternary branches with multiple siblings need a Fragment wrapper. A ternary branch in JSX that returns two or more adjacent elements must be wrapped in <>...</>. Without it, TypeScript/JSX compilation fails immediately. This burned commit 107a664 in OrganizerDashboard.tsx. Watch for this pattern in dashboard components where a branch renders an icon + label or control + tooltip side by side.

2026-09-09

Firebase Functions v2 secrets must be declared in the function's secrets array to get IAM access. Adding a secret via firebase functions:secrets:set does NOT automatically grant the function access. Declare with defineSecret('KEY_NAME') and list in secrets: [...] of onRequest(). Without this, resolveCredential() silently returns null.

2026-09-09

Geographic collection runners must fail hard when venue has no coordinates. The runner defaulted to lat: 0, lon: 0 when venue.coordinates was missing, silently running all collection jobs against the Gulf of Guinea. Missing coordinates must be treated as a fatal precondition — fail immediately and run no jobs.

2026-09-08

Test helper opts parameter needs a default when all properties are optional. When a test helper has all optional properties, the opts parameter must default to {}. Without it, calling makeReqRes() with no arguments throws at runtime. Always add = {} when all properties are optional.

2026-09-05

A data collection pipeline with no downstream reader is incomplete. When adding a new data category, always trace the full path from collection → normalization → consumer in the same sprint. An unread collection is dead weight — its value can't be validated.

2026-09-02

New routes with where()+orderBy() must ship their Firestore composite indexes in the same commit. Without composite indexes, Firestore rejects these queries at runtime with "requires an index." Single-field where() without orderBy() does not require a composite index.

2026-08-31

Use vi.hoisted() when Vitest mock factories must close over reassignable variables. Without hoisting, the variable is not initialized before the factory runs. Pattern: const { mockGet } = vi.hoisted(() => ({ mockGet: vi.fn() })).

2026-08-31

Test files in frontend/src/ must be excluded from the app tsconfig. Vite resolves tsconfig.app.json at build time and will attempt to bundle test files if not excluded. Add "exclude": ["src/**/*.test.tsx", "src/**/*.test.ts"] to frontend/tsconfig.app.json.

2026-08-30

Scripts in scripts/ must self-configure NODE_PATH. Set process.env.NODE_PATH = path.join(__dirname, '..', 'functions', 'node_modules') and call Module._initPaths() at the top of any script that requires packages from functions/node_modules.

2026-08-28

New Firestore collections must get a rules stub immediately. Add a named match /X/{docId} stub in the same commit as any new db.collection('X') call. The catch-all protects it, but intent is invisible without the stub.
