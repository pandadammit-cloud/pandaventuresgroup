1. Platform Overview

DockBound is a cruise intelligence platform with two distinct audiences:

Consumer side — Cruise travelers who purchase port guides (DockGuides) for their itinerary, giving them port-by-port intelligence for their trip.

Professional side — Travel advisors and agencies who use DockBound's live intelligence dashboard to monitor their entire book of cruise business, powered by Travefy trip data and DockBound's proprietary DOCK scoring system.

Key concept — DockScore (DOCK): A proprietary port accessibility and congestion rating composed of D (Distance Friction), O (Operational Load), C (Conditions), K (Key Risks), each scored 1–5. A static baseline reflects normal conditions; a dynamic adjusted score incorporates live signals (ship volume, weather, advisories). A port is flagged "at risk" when dynamic exceeds static by ≥ 0.5. The score is displayed as a 4-segment gradient bar (Relaxed → Manageable → Elevated → High-Constraint) with a dotted marker for typical conditions and a solid marker for the specific sail date. When a sail date is provided, a comparison table shows how Crowds, Return logistics, and Ship volume compare to a typical day.

3. User Journeys

Journey 1 — Traveler: Self-Serve Paid DockGuide

A cruise passenger discovers DockBound, previews their itinerary, and purchases a full DockGuide.

  1. Discover — Arrives at Compass Landing (/) or Traveler Landing (/for-travelers) via search, social, or advisor referral
  2. Browse — Searches for their cruise on Cruise Selection (/micro-selection) by cruise line, ship, sail date, or region. Cruise-line search uses a cascading drill-down: selecting a line reveals ship choices and month filters before reaching a results list — avoids truncation from broad queries.
  3. Preview — Views port-by-port itinerary preview (/preview) with sample port guide content, DockScore teaser, and weather sample
  4. Authenticate — Signs up or logs in (/auth); if not yet authenticated when clicking "Buy", session stores cruise and redirects back post-auth
  5. Purchase — Completes Stripe checkout (/payment-checkout)
  6. Confirm — Payment success page (/payment-success) with cruise summary
  7. Access — Full DockGuide on user dashboard (/dashboard): weather, travel alerts, local currency, tours, full port guide text, DOCK diagnostic

Journey 2 — Traveler: Freemium Access

A traveler receives free/partial DockGuide access — via advisor referral, promotional access, or sign-up without purchase.

  1. Arrive — May come via advisor referral link or direct sign-up
  2. Authenticate — Signs up or logs in (/auth)
  3. Access — Dashboard shows freemium content; locked sections display an upgrade prompt
  4. Upgrade — Can purchase full access from upgrade prompt or /upgrade/:orderId

Journey 3 — Advisor: Joins Solo, Manual Roster (No Travefy)

A travel agent signs up independently, builds their client roster manually, and uses the intelligence dashboard to monitor their book of business.

  1. Sign up — Goes to /auth?mode=signup&advisor=true. No invite code required — independent advisor signup is open. Role set to independentAdvisor via registerAdvisorRole CF.
  2. Subscribe — Selects a plan (Basic / Professional / Engage) via Stripe checkout. Promo/coupon codes can be applied at checkout.
  3. Build roster — Adds travelers one at a time (name, email, cruise, optional phone/reference ID and SMS consent)
  4. Monitor — Uses the Advisor Dashboard: Sailings tab (Upcoming Sailings, Port Conditions intelligence), Clients tab (roster management), Port Tools (port guides + congestion calendar)
  5. Customize — Configures which guide sections clients see and in what order (Guide Settings in Port Tools tab; port-specific content requires Professional+)
  6. Deliver — Sends port guide emails to travelers; looks up port guides and DockScores for clients; prints itineraries and port guides

Journey 4 — Advisor: Joins Solo, Links Travefy

An advisor links their Travefy account to DockBound, syncing cruise trips automatically and enriching them with DockBound intelligence.

  1. Sign up & subscribe — Same as Journey 3, steps 1–2
  2. Connect Travefy — In Settings tab, enters credentials; DockBound stores AccessToken in agents/{uid}.travefyConnection
  3. Sync trips — Clicks "Sync Now"; trips pulled from Travefy API and stored in agents/{uid}/trips subcollection
  4. Auto-sync — Nightly scheduled Cloud Function (scheduledTravefyTripSync) runs at 2am ET
  5. View enriched trips — DockScore and port guide data overlaid on synced trip list
  6. Enrich back — Writes DockBound Info TripEvents back into Travefy port days; enrichment registry stored in travefyEnrichments collection
  7. Monitor — All intelligence dashboard views draw from synced trip data

Journey 5 — Agency Host: Joins With Travefy

An agency admin provisions a DockBound agency, imports their advisor team, and oversees intelligence across all agents who sync Travefy.

  1. Sign up — Account provisioned with role agencyhost (by admin or self-service)
  2. Create agency — Sets agency name, website, phone in Agency Hub (/agency-hub)
  3. Import agents — Uploads CSV of advisor roster at /agency-hub/import
  4. Invite agents — System sends email invitations to each advisor
  5. Agents onboard — Each advisor follows Journey 4 (links their own Travefy account)
  6. Monitor — Agency host reviews agent activity reports and referral analytics at /agency-hub/reports
  7. Manage roster — Views agents by status (active/invited/suspended) at /agency-hub/roster

Journey 6 — Agency Host: Joins Without Travefy

An agency admin uses DockBound to manage advisor and traveler intelligence without any Travefy integration — relying entirely on manual roster entry by each advisor.

  1. Sign up & create agency — Same as Journey 5, steps 1–2
  2. Import & invite agents — CSV import + invite emails
  3. Agents build rosters manually — Each advisor follows Journey 3
  4. Monitor — Agency host reviews agent activity and referral reports

Journey 7 — Advisor: Invited by Agency Host

An advisor receives a roster invitation email from their host agency and joins DockBound as part of that agency's team.

  1. Receive invite — Gets email triggered by sendRosterInviteEmail Cloud Function (fires on roster doc creation)
  2. Click link — Directed to sign-up flow with agency pre-linked via referral code or invite token
  3. Sign up — Creates account; linkAgentRoster Cloud Function associates them with the agency roster entry
  4. Activate — Roster entry status changes from invited → active
  5. Use platform — Advisor proceeds with Journey 3 (manual) or Journey 4 (with Travefy)

Journey 8 — Traveler: Referred by an Advisor

An advisor sends a referral link to a traveler; the traveler joins DockBound and their sign-up is attributed to that advisor.

  1. Advisor shares link — Advisor distributes their unique referral link or a DockGuide link to a client
  2. Traveler clicks — Lands on DockBound with referral attribution tracked in session
  3. Traveler signs up — Creates account; agencyOnReferralSignup Cloud Function records referral attribution
  4. Traveler accesses guide — Receives freemium or paid access depending on advisor's setup
  5. Advisor gets credit — Referral counted in agency reports

Journey 9 — Advisor: Delivers Port Guide to Traveler

An advisor proactively sends a client's port guide to them by email for a specific port day.

  1. Identify — Advisor sees in the Sailings tab an upcoming sailing with clients
  2. Select — From the Clients tab, selects the traveler and clicks "Send Guide" — or from the Sailings tab, bulk-sends to all clients on a sailing
  3. Send — sendPortGuideEmail / sendBulkPortGuideEmail Cloud Functions deliver via SendGrid; logged in guide_send_log
  4. Traveler receives — Email with port-day itinerary and guide content

Journey 10 — Traveler: Day-of Port Experience

A traveler is arriving at port today and uses DockBound on their phone — potentially with limited ship Wi-Fi — to navigate the port.

  1. Open app — Accesses /dashboard from mobile browser; today's port highlighted
  2. Read guide — Full DockGuide text: snapshot, transport, safety contacts, food, budget tips
  3. Check alerts — Views any current travel advisory for the destination country
  4. Convert currency — Quick lookup of local exchange rate
  5. Book tour — Browses and books Viator tours for the port
  6. Check DockScore — Sees current congestion/accessibility rating with opState badge
