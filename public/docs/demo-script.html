Platform Overview

The Problem We Solve

😕

Without DockBound

Cruise port days are a black box. Travelers arrive with no context — long tender queues, unexpected customs delays, congested piers, port advisories they never heard about.

📞

Advisors Are Reactive

Travel advisors learn about port issues when their clients text from the ship — after the problem is already happening. There's no early-warning layer built for cruise port conditions.

⚓

DockBound Changes That

Per-port intelligence — DOCK scores, port guides, congestion forecasts, State Dept. advisories, and weather — delivered to both traveler and advisor before the ship ever docks.

🔄

Live, Dynamic Data

Scores update based on actual ship counts, weather, and advisories. An "Elevated" port can become "High-Constraint" overnight when three additional ships add calls on the same date.

Talking point: DockBound is not a booking tool or a CRM. It's the intelligence layer that sits between the cruise itinerary and the port day itself.

DOCK Score

What is a DOCK Score?

D
Distance Friction

How hard is it to get from ship to your destination? Pier location, tender requirement, transport availability, and transit time all factor in.

O
Operational Load

Port traffic and capacity — how many ships are in port, how crowded the pier is, infrastructure limits. The most dynamic of the four components.

C
Conditions

Weather severity and State Dept. advisory level for that port. Updated live as forecasts change and as advisories are issued or lifted.

K
Key Risks

Port-specific hazards: known scams, infrastructure issues, safety concerns, or logistical gotchas that don't fall neatly into the other three components.

Relaxed (1–2)
Manageable (2–3)
Elevated (3–4)
High-Constraint (4–5)
Talking point: The static baseline is computed from the port guide content. The dynamic score is computed fresh each time using live ship counts, weather data, and State Dept. advisories. The delta between static and dynamic is the "drift" — a positive drift is the AT-RISK signal.
