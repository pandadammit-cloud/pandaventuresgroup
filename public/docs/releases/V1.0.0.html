Acceptance Criteria

DOCK Scoring — Baseline + Adjusted Scores

Acceptance Criteria

Partner API — 4 Endpoints

Acceptance Criteria
  • Given a valid API key, when GET /cruiseItineraryApi is called with a cruise ID, then the normalized itinerary is returned

  • Given a paid API key, when GET /dockScoreApi is called with a sail date, then the adjusted DOCK score is returned; without a sail date, the baseline is returned
  • Given any API key, when the rate limit is exceeded (sandbox tier), then a 429 response is returned
