Lessons Learned (new this run)

2026-09-05 — CJS/ESM compatibility for admin scripts

.cjs scripts in an ESM project ("type": "module" in package.json) must use CommonJS require() / module.exports, never import / export. The .cjs extension forces CommonJS regardless of the project's default module type — but developers familiar with ESM will instinctively write import statements. backlog-seed.cjs and backlog-update.cjs both failed at runtime with "Cannot use import statement outside a module" and required an immediate fix commit (47ffa58). When generating new .cjs scripts, verify the extension first and use require() throughout. If ESM features (top-level await, etc.) are needed, use .mjs extension instead.
